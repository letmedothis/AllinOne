# 项目文档导航

项目文档按用途归档，新增文档请放入对应分类目录，截图等附件统一放在 `assets/`。

## 目录

- [01 用户与操作](01-用户与操作/使用手册.md)：业务用户和系统管理员使用说明。
- [02 设计与交付](02-设计与交付/)：基础架构设计、供应链业务设计和交付计划。
  - [基础设计](02-设计与交付/基础设计/)
  - [供应链专项](02-设计与交付/供应链专项/)
- [03 研发与质量](03-研发与质量/)：审计、修复、回归、复盘和待办记录。
- [04 部署与运维](04-部署与运维/SQL_EXECUTION_ORDER.md)：数据库初始化和部署相关说明。
- [assets](assets/)：手册截图与浏览器回归截图，不单独承载说明文档。

## 文档归档约定

- 设计类文档放入 `02-设计与交付`，按基础设计或供应链专项归档。
- 一次性审查、测试和问题处理记录放入 `03-研发与质量`，文件名保留日期便于追溯。
- 用户可直接阅读的操作说明放入 `01-用户与操作`。
- 文档内链接使用相对路径，避免使用本机绝对路径。
