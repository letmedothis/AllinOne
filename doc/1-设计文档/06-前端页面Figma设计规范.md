## 一、设计系统规范

### 1.1 色彩体系

| Token | 色值 | 用途 |
|-------|:----:|------|
| --el-color-primary | #409EFF | 主色（按钮/链接/激活态） |
| --el-color-success | #67C23A | 成功（已发布/已提交） |
| --el-color-warning | #E6A23C | 警告（仪表盘） |
| --el-color-danger | #F56C6C | 危险（删除/错误） |

| --el-bg-color-page | #F5F7FA | 页面次背景 |

| --el-text-color-regular | #606266 | 常规文字 |

## 四、与 Figma 设计系统对接指南

当配置 Figma API Token 后，可按以下步骤创建设计稿：

### 4.1 准备

```bash
# 1. 创建 Figma 文件
/figma-create-new-file → fileKey

# 2. 连接设计系统库
# 使用 Element Plus Figma 组件库
# https://www.figma.com/community/file/1103923812229893167
```

### 4.2 设计流程

1. **建立颜色变量**: 在 Figma 中创建 Color Variables 匹配 Element Plus 色板
2. **建立文字样式**: 创建 Text Styles 匹配上述字体规范
3. **创建间距变量**: 创建 Spacing Variables
4. **导入组件**: 从 Element Plus 社区库拖入 el-table, el-form, el-button 等组件
5. **拼装页面**: 按上述布局结构拼接每个页面
6. **设置交互**: 关联弹窗、跳转、提交等交互流程

### 4.3 导出与开发者交付

```bash
# 导出设计稿为图片（用于文档）
```

## 五、设计验收清单

| 检查项 | 标准 |
|--------|------|
| 色彩一致 | 主色/成功/警告/危险 全部使用 Element Plus 色板变量 |
| 字体层级 | 16px/14px/12px 三层级，不超过三种字重 |
| 间距统一 | 所有间距为 4px 的整数倍（8/12/16/24/32） |
| 圆角一致 | 按钮/输入框 4px，卡片 6px，弹窗 8px |
| 响应式 | 大屏 >1200px，中屏 >992px，小屏 >768px |
| 可访问性 | 所有操作按钮有 Tooltip，颜色对比度 ≥4.5:1 |
| 权限联动 | 按钮级权限通过 v-hasPermi 控制显示/隐藏 |

| Expose | 说明 |
|--------|------|
| getSheetData() | 获取所有工作表数据 |
| loadData(data) | 加载指定数据到表格 |
| uploadImage(file) | 上传图片到服务器，返回 URL（替代 base64 嵌入） |

**图片上传流程：**
1. 用户在 Luckysheet 中插入/粘贴图片
2. CollectSheet 拦截图片插入事件
3. 调用 uploadImage(file) 上传至 POST /common/upload
4. 返回 URL 保存在单元格中（而非 base64 数据）
5. form_data 中的图片引用仅为 KB 级
