### 1.2 当前项目事实

- 后端是 8 模块 Maven 工程，共 326 个 Java 文件；前端为 Vue 3 + TypeScript，共约 214 个 `.ts/.vue` 文件。
- 当前已有 Java 测试主要集中在 `allinone-collect`、`allinone-report` 和 `allinone-common`，共发现 6 个测试类；`allinone-framework`、`allinone-system`、`allinone-quartz`、`allinone-generator`、`allinone-admin` 尚无正式测试目录或测试依赖。
- 前端已有 `npm run test:contracts`，目前只有一个静态契约测试；`npm run build:prod` 只能证明编译成功，不能证明交互、权限和并发行为正确。
- 当前工作目录未检测到 Git 元数据。实施前必须制作源代码与数据库快照；若后续纳入 Git，再按本文“补丁批次”作为提交边界。
- 本计划是修复设计，不代表任何问题已经完成修复，也不把静态检查结果等同于真实环境回归结果。

### 1.3 关键设计决策

1. **不全局开启 `mapUnderscoreToCamelCase`。** 当前 Mapper 同时存在显式 `resultMap` 和 `resultType`，全局切换可能改变未审查查询的映射行为。应在受影响 Mapper 中使用显式列和显式 `resultMap`。
2. **可见性不等于编辑权。** 部门数据范围只决定“能否看到”；编辑 Sheet 必须满足报表属主、管理员或显式 Sheet 授权之一。
3. **逻辑删除必须贯穿读、改、关联查询。** 所有 byId、update、join、授权入口统一过滤未删除状态。
4. **数据库是业务事实源，Quartz 是可重建投影。** 调度更新必须先完整校验，再执行带补偿的同步；应用启动不得 `scheduler.clear()`。
5. **回写配置错误必须在保存配置时失败。** 提交数据时仍保留防御性校验，但不得静默跳过。
6. **JWT 不再进入 URL。** JimuReport/JimuBI iframe 使用一次性短时 ticket，JWT 本身具有 `exp`，查询串和访问日志中不出现长期令牌。
7. **安全修复优先选择失效会话，而不是保留过期权限。** 第一版可以在授权变化时强制受影响用户重新登录；后续再优化为无感刷新。
8. **DDL 安全不能只依赖关键字黑名单。** 代码生成器必须使用单语句 AST 白名单和服务端生成的规范化 DDL；关键字过滤只作为第二道防线。
