# 数电票真实票样投放目录

把脱敏真实数电票(蓝字)XML 放入本目录(每张一个文件,建议命名 `digital-invoice-<序号>.xml`),并告知仓库维护者文件已就位,即可执行 M3 的字段映射校准与回归测试。

要求:

- 内容**必须脱敏**:税号、名称、金额、地址、开户行等替换为示例值或打码,结构保持不变;
- 至少提供 1 张含多行商品/服务清单的样例;
- 请勿包含真实个人/企业隐私信息与真实税务票据数据。

校准与验收口径见 `doc/M3_数电票解析_契约.md` §4–§6。当前 `DigitalInvoiceXmlParser` 处于诊断骨架状态,收到本目录样例后回填映射并建立回归测试。
