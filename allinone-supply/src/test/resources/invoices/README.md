# 数电票真实票样投放目录

把真实数电票(蓝字)XML 放入本目录供开发/校准使用;命名建议 `digital-invoice-<序号>.xml` 并告知仓库维护者。

## 安全约定(重要)

- **含真实信息的原始文件一律不入库**(.gitignore 已忽略 `digital-invoice-01.xml` 及 `digital-invoice-*.xml` 原文件);
- 需要固化回归样例时,请生成**掩码副本** `digital-invoice-<序号>.fixture.xml`:结构逐节点不变,仅把企业名称/税号/20位票号/电话/地址/银行账号/签名值等替换为演示值;
- 已校准夹具示例:`digital-invoice-01.fixture.xml`(源自真实票样 `digital-invoice-01.xml`,标识字段已打码)。

## 校验与验收

字段映射与验收口径见 `doc/02-设计与交付/供应链专项/M3_数电票解析_契约.md` §4–§5。当前已完成单行数电票校准;如能补充含**多行商品/服务清单**的票样,将补回归验收(契约 §5 项 2)。
